# Detergents Delivered — Static UI Mockup

Polished static HTML/CSS/JS preview for **detergentsdelivered.com**.

> **UI mockup only** — not the production Next.js app in the private `detergents-delivered` repo. Payments and fulfillment are not live.

## Pages

- `index.html` — Home
- `shop.html` — Product grid + filters
- `product.html` — Product detail
- `cart.html` / `checkout.html` — Cart (localStorage) + demo checkout
- `account.html` — Account shell + sample orders
- `delivery.html` — ZIP checker
- `faq.html`, `contact.html`, `terms.html`, `privacy.html`, `refunds.html`

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

## GitHub Pages

Published from `main` / root for public viewing without GitHub login.
